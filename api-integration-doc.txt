# Flutter অ্যাপ — API ইন্টিগ্রেশন গাইড (TruckCalc / Freight2You Backend)

এই ডকুমেন্ট **একটি REST API ব্যাকএন্ড** (Express, MongoDB, JWT) এর সাথে Flutter মোবাইল অ্যাপ পুরোপুরি কানেক্ট করতে প্রয়োজনীয় তথ্য দেয়। বেস URL প্রোডাকশন/স্টেজিং এ পরিবর্তন করুন।

---

## ১. বেস ইনফরমেশন

| আইটেম | মান |
|--------|-----|
| API প্রিফিক্স | `/api/v1` |
| বিভিন্ন এন্ডপয়েন্ট | নিচের টেবিল অনুযায়ী |
| ডিফল্ট `Content-Type` | `application/json` |
| হেলথ চেক | `GET /api/v1/status` |
| রুট নট ফাউন্ড | `404` — `{ success: false, message: "API route not found!", ... }` |

**উদাহরণ বেস URL:** `https://your-domain.com`  
সম্পূর্ণ পাথ: `https://your-domain.com/api/v1/auth/login`

স্ট্যাটিক ফাইল (প্রোফাইল ইমেজ ইত্যাদি সার্ভারে সেভ হলে) সাধারণত এগুলো দিয়ে সার্ভ হয়:

- `/uploads`, `/images`, `/media`, `/documents`

## ৩. অথেনটিকেশন

### ৩.১ হেডার

সুরক্ষিত রুটে:

```http
Authorization: Bearer <accessToken>
```

টোকেন ফরম্যাট সার্ভার কোডে `Bearer` দিয়ে শুরু হতে হবে (স্পেসের পর আসল JWT)।

### ৩.২ ইউজার রোল (`USER_ROLES`)

ব্যাকএন্ডে সংজ্ঞায়িত রোল:

- `super_admin`
- `admin`
- `user`
- `organizer`

প্রতিটি রুট নির্দিষ্ট রোল চায়; ভুল রোলে `403`।

### ৩.৩ লগইন রেসপন্স (সাধারণ)

লগইন সফল হলে `data` তে সাধারণত থাকে:

```json
{
  "accessToken": "...",
  "refreshToken": "...",
  "role": "user"
}
```

সার্ভার **httpOnly কুকি** তেও `refreshToken` সেট করতে পারে। মোবাইল অ্যাপে কুকি নির্ভর করবেন না — **JSON বডি থেকে `refreshToken` সিকিউর স্টোরেজে** রাখুন।

### ৩.৪ রিফ্রেশ টোকেন — গুরুত্বপূর্ণ (Flutter)

**`POST /api/v1/auth/refresh-token`** বর্তমান ইমপ্লিমেন্টেশনে `req.cookies.refreshToken` থেকে রিফ্রেশ টোকেন নেয়।

মোবাইলে কুকি স্বয়ংক্রিয় নাও আসতে পারে। **ওয়ার্কআরাউন্ড:** লগইনের পর যে `refreshToken` বডিতে পান, রিফ্রেশ রিকোয়েস্টে ম্যানুয়ালি কুকি হেডার পাঠান:

```http
POST /api/v1/auth/refresh-token
Cookie: refreshToken=<সংরক্ষিত_refresh_token>
```

অথবা একই ডোমেইনে `dio` + কুকি জার ব্যবহার করুন। রিফ্রেশ সফল হলে রেসপন্স:

```json
{
  "statusCode": 200,
  "success": true,
  "message": "Token refreshed successfully",
  "data": {
    "accessToken": "..."
  }
}
```

> যদি ভবিষ্যতে ব্যাকএন্ড `body`-তে `refreshToken` গ্রহণ করে, তখন কুকি ওয়ার্কআরাউন্ড সরিয়ে দেওয়া যাবে।

### ৩.৫ Flutter টিপস (সংক্ষেপ)

- `flutter_secure_storage` — `accessToken`, `refreshToken`
- `dio` — ইন্টারসেপ্টরে `401` হলে রিফ্রেশ, তারপর আবার অরিজিনাল রিকোয়েস্ট
- মাল্টিপার্ট — প্রোফাইল আপডেট ও মেসেজ (নিচে)

## ৪. সম্পূর্ণ API তালিকা

সব পাথ নিচে **`/api/v1` এর পরের অংশ**। সম্পূর্ণ URL = `BASE_URL + /api/v1 + path`।

### ৪.১ Auth — `/auth`

| মেথড | পাথ | অথ | বডি / নোট |
|--------|------|-----|------------|
| POST | `/signup` | না | `email` (optional), `password` (min 6), `name` (optional), `phone` (optional, libphonenumber বৈধ), `address` (optional) |
| POST | `/login` | না | `email` **অথবা** `phone`, `password` (min 6), `deviceToken`?, `rememberMe`? — তারপর Passport `local` |
| POST | `/custom-login` | না | একই লগইন বডি; কাস্টম লগইন সার্ভিস |
| POST | `/admin-login` | না | অ্যাডমিন লগইন |
| GET | `/google` | না | ব্রাউজারে Google OAuth শুরু |
| GET | `/google/callback` | না | কলব্যাক (ওয়েব রিডাইরেক্ট; মোবাইলে সাধারণত ডিপ লিঙ্ক/ওয়েবভিউ পরিকল্পনা লাগে) |
| POST | `/verify-account` | না | `email`, `oneTimeCode`; `phone` optional — নতুন ইউজার ভেরিফাই বা রিসেট ফ্লো |
| POST | `/forget-password` | না | `email` **অথবা** `phone` |
| POST | `/reset-password` | না | হেডার: `Authorization` — OTP ভেরিফিকেশনের পর `verify-account` রেসপন্সের **`data.token`** (টোকেন মডেলের স্ট্রিং)। বডি: `newPassword`, `confirmPassword` (min 8)। যদি `Bearer` দিয়ে মিল না খায়, ব্যাকএন্ড `Token.findOne({ token })` ব্যবহার করে — প্রয়োজনে শুধু টোকেন স্ট্রিং হেডারে দিন (টিমের সাথে মিলিয়ে নিন)। |
| POST | `/resend-otp` | না | `email` / `phone`, `authType` (`resetPassword` \| `createAccount`) |
| POST | `/change-password` | হ্যাঁ (user/admin) | `currentPassword`, `newPassword`, `confirmPassword` |
| DELETE | `/delete-account` | হ্যাঁ | `password` |
| POST | `/refresh-token` | না | কুকি ওয়ার্কআরাউন্ড (উপরে) |
| POST | `/social-login` | না | `appId`, `deviceToken` |
| POST | `/logout` | হ্যাঁ | — |

## ৫. রিয়েলটাইম — Socket.IO

সার্ভার `socket.io` চালু করে; CORS `*`।

- কানেক্ট করুন **একই হোস্ট/পোর্ট** এ যেখানে HTTP API চলে (উদাহরণ `https://api.example.com` বা `http://IP:PORT`)।
- ইভেন্ট:
  - **`join-room`** — আর্গুমেন্ট: `roomId` (স্ট্রিং); রুম কী: `room:<roomId>`
  - **`leave-room`** — একইভাবে `roomId`

Flutter প্যাকেজ: `socket_io_client`। JWT হ্যান্ডশেক এই ব্যাকএন্ডের `socketHelper`-এ দেখা যায়নি — শুধু কানেকশন ও রুম জয়িন।

## ৬. ইন্টিগ্রেশন চেকলিস্ট (একটি ডক দিয়ে পুরো অ্যাপ)

1. **কনফিগ** — `BASE_URL`, পরিবেশ (`dev`/`prod`).
2. **Auth** — সাইনআপ → OTP ইমেইল → `verify-account` → টোকেন স্টোর; অথবা লগইন → `407`-স্টাইল প্রম্পট হলে OTP ফ্লো।
3. **টোকেন** — প্রতিটি API তে `Authorization: Bearer …`; 401 হলে রিফ্রেশ (`Cookie` ট্রিক বা ভবিষ্যৎ বডি API).
4. **প্রোফাইল** — `GET/PATCH /user/profile` (PATCH = multipart যদি ফাইল থাকে).
5. **ট্রাক ক্যালক** — `POST/GET … /calculations`।
6. **সাবস্ক্রিপশন** — প্ল্যান লিস্ট → চেকআউট বা `create` — Stripe ফ্লো প্রোডাক্ট রিকোয়ারমেন্ট অনুযায়ী।
7. **চ্যাট/মেসেজ** — চ্যাট তৈরি/লিস্ট → মেসেজ পোস্ট (multipart) → Socket রুম জয়িন।
8. **স্ট্যাটিক ইমেজ URL** — আপলোড রেসপন্স/প্রোফাইল `profile` পাথ জোড়া দিয়ে দেখান।
9. **এরর হ্যান্ডলিং** — `success: false`, `errorMessages` ইউজার-ফ্রেন্ডলি মেসেজ।

## ৭. উৎস কোড রেফারেন্স (ব্যাকএন্ড)

রুট মানচিত্র: `src/routes/index.ts` → প্রতিটি মডিউল `*.route.ts`।  
রেসপন্স ওয়্রাপার: `src/shared/sendResponse.ts`।  
অথ মিডলওয়্যার: `src/app/middleware/auth.ts`।
