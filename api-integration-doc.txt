# Flutter অ্যাপ — API ইন্টিগ্রেশন গাইড (TruckCalc / Freight2You Backend)

এই ডকুমেন্ট **একটি REST API ব্যাকএন্ড** (Express, MongoDB, JWT) এর সাথে Flutter মোবাইল অ্যাপ পুরোপুরি কানেক্ট করতে প্রয়োজনীয় তথ্য দেয়। বেস URL প্রোডাকশন/স্টেজিং এ পরিবর্তন করুন।

## ২. স্ট্যান্ডার্ড রেসপন্স ফরম্যাট

```json
  "meta": {
    "page": 1,
```

`meta` শুধু পেজিনেশন যেখানে আছে সেখানেই থাকে।

```json
  ],
  "stack": "...(শুধু non-production)..."
}
```

### 4.4 Calculations — `/calculations`

All routes require authentication: `user`, `admin`, or `super_admin`.

| Method | Path | Description |
|--------|------|-------------|
| POST | `/` | Create a new calculation record |
| GET | `/` | List calculations (with pagination/filtering) |
| GET | `/stats` | Get calculation statistics for the current user |
| GET | `/export` | Export all user calculations in flattened format |
| GET | `/:id` | Get one calculation by ID |
| DELETE | `/:id` | Delete one calculation by ID |

#### Request body for POST /api/v1/calculations

```json
{
  "type": "LOAD" | "GOAL" | "COST",
  "loadData": { ... },
  "goalData": { ... },
  "costData": { ... }
}
```

- `type` is required.
- For `LOAD`, include `loadData`.
- For `GOAL`, include `goalData`.
- For `COST`, include `costData`.
- The backend validation currently requires all numeric fields defined in the schema, including calculated result fields.

#### `loadData` fields (LOAD calculator)

- `baseRate`: number
- `fuelSurcharge`: number
- `loadedMiles`: number
- `tolls`: number
- `dhMiles`: number
- `dhRate`: number
- `bonus`: number
- `driverPercentage`: number
- `costPerMile`: number
- `totalRevenue`: number
- `totalProfit`: number
- `totalFSC`: number
- `totalDH`: number
- `totalMiles`: number
- `compensationPerMile`: number
- `totalCost`: number
- `profitPerMile`: number
- `driverPay`: number
- `ownerPay`: number

The server recalculates derived values for LOAD, such as:
- `totalFSC`
- `totalDH`
- `totalRevenue`
- `totalMiles`
- `compensationPerMile`
- `totalCost`
- `profitPerMile`
- `totalProfit`
- `driverPay`
- `ownerPay`

#### `goalData` fields (GOAL calculator)

- `desiredWeeklyProfit`: number
- `costPerMile`: number

- `daysPerWeek`: number
- `maxMilesPerDay`: number

- `minTargetRate`: number
- `totalRevenue`: number
- `totalCost`: number
- `maxDHPerDay`: number

The server recalculates GOAL output values such as:

The server recalculates COST output values such as:
- `totalWeeklyFixed`
- `weeklyFuelCost`
- `weeklyOilChangeCost`
- `weeklyTireCost`
- `weeklyMaintenanceCost`
- `totalWeeklyVariable`
- `totalWeeklyOperatingCost`
- `trueCPM`

#### GET /api/v1/calculations

Returns a paginated list of calculation records for the authenticated user.

Supported query parameters:
- `page` (default 1)
- `limit` (default 10)
- `sort` (e.g. `-createdAt`)
- `fields` (comma-separated field list)
- `searchTerm`
- any exact field filter for calculation fields

#### GET /api/v1/calculations/stats

Returns user-specific calculation statistics:
- `totalCalculations`
- `planLeftDays`
- `subscriptionStatus`
- `planName`

#### GET /api/v1/calculations/export

Returns all calculations for the user in a flattened format suitable for export.
Each exported row contains:
- `id`
- `type`
- `createdAt`
- all fields from the selected calculator object (`loadData`, `goalData`, or `costData`)

#### GET /api/v1/calculations/:id

Returns a single calculation record.

#### DELETE /api/v1/calculations/:id

Deletes a single calculation record for the authenticated user.

## ৫. রিয়েলটাইম — Socket.IO

সার্ভার `socket.io` চালু করে; CORS `*`।

- কানেক্ট করুন **একই হোস্ট/পোর্ট** এ যেখানে HTTP API চলে (উদাহরণ `https://api.example.com` বা `http://IP:PORT`)।
- ইভেন্ট:
  - **`join-room`** — আর্গুমেন্ট: `roomId` (স্ট্রিং); রুম কী: `room:<roomId>`
  - **`leave-room`** — একইভাবে `roomId`

Flutter প্যাকেজ: `socket_io_client`। JWT হ্যান্ডশেক এই ব্যাকএন্ডের `socketHelper`-এ দেখা যায়নি — শুধু কানেকশন ও রুম জয়িন।

## ৬. ইন্টিগ্রেশন চেকলিস্ট (একটি ডক দিয়ে পুরো অ্যাপ)

1. **কনফিগ** — `BASE_URL`, পরিবেশ (`dev`/`prod`).
2. **Auth** — সাইনআপ → OTP ইমেইল → `verify-account` → টোকেন স্টোর; অথবা লগইন → `407`-স্টাইল প্রম্পট হলে OTP ফ্লো।
3. **টোকেন** — প্রতিটি API তে `Authorization: Bearer …`; 401 হলে রিফ্রেশ (`Cookie` ট্রিক বা ভবিষ্যৎ বডি API).
4. **প্রোফাইল** — `GET/PATCH /user/profile` (PATCH = multipart যদি ফাইল থাকে).
5. **ট্রাক ক্যালক** — `POST/GET … /calculations`।
6. **সাবস্ক্রিপশন** — প্ল্যান লিস্ট → চেকআউট বা `create` — Stripe ফ্লো প্রোডাক্ট রিকোয়ারমেন্ট অনুযায়ী।
7. **চ্যাট/মেসেজ** — চ্যাট তৈরি/লিস্ট → মেসেজ পোস্ট (multipart) → Socket রুম জয়িন।
8. **স্ট্যাটিক ইমেজ URL** — আপলোড রেসপন্স/প্রোফাইল `profile` পাথ জোড়া দিয়ে দেখান।
9. **এরর হ্যান্ডলিং** — `success: false`, `errorMessages` ইউজার-ফ্রেন্ডলি মেসেজ।

## ৭. উৎস কোড রেফারেন্স (ব্যাকএন্ড)

রুট মানচিত্র: `src/routes/index.ts` → প্রতিটি মডিউল `*.route.ts`।  
রেসপন্স ওয়্রাপার: `src/shared/sendResponse.ts`।  
অথ মিডলওয়্যার: `src/app/middleware/auth.ts`।  

এই ফাইলগুলো পরিবর্তন হলে ডকুমেন্ট আপডেট করুন।
